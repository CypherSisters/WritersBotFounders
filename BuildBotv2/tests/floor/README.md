# Floor tests

The floor is the list nobody goes below: X1 to X20 in `docs/zones/ZONES_TOGETHER.md` section 4, plus the agent deny rules from `docs/09_AGENT_SECURITY.md` (D34, written by the security pass). Each item gets one or more tests here. They run in three places: `puffpai check --floor` (a provider's own suite), the Core self-test at every start (a fast subset, `core.selftest`), and Caretaker daily and after any provider install or update.

Every lane runs this folder before it commits (10 "Rules for every lane").
