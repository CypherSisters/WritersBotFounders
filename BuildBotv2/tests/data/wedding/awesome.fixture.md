# A stand-in for the awesome-selfhosted list (our own words; see SOURCE.md)

## Analytics

- [Swetrix](https://github.com/Swetrix/selfhosting) - Web analytics that track a site's visits and monitor its speed. `AGPL-3.0` `Docker`
- [HitKeep](https://github.com/pascalebeier/hitkeep) - Web analytics with goals and shop tracking, in one program. `MIT` `Go`

## Automation

- [Apache Airflow](https://github.com/apache/airflow) - Write, schedule and monitor workflows as code. `Apache-2.0` `Python`
- [Kestra](https://github.com/kestra-io/kestra) - A platform to build, schedule and monitor workflows. `Apache-2.0` `Java`

## Software Development

- [Middleware](https://github.com/middlewarehq/middleware) - A tool designed to measure engineering teams with DORA numbers. `Apache-2.0` `Python`

## Bookmarks

- [NeonLink](https://github.com/AlexSciFier/neonlink) - A bookmark service with its own design, run with Docker. `MIT` `Nodejs`
